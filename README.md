# Exercícios de Lógica de Programação — Python

Soluções das questões 01 a 20 da Lista 02 de Lógica de Programação — Python.

## Organização

Cada questão está em um arquivo `.py` independente:

- `01_cadastro_perfil.py`
- `02_calculadora.py`
- ...
- `20_sistema_academico.py`

## Como abrir no VS Code

1. Extraia a pasta/ZIP.
2. Abra o VS Code.
3. Vá em **File > Open Folder** e selecione a pasta `EXERCICIOS_LOGICA_PYTHON_2026_2_ESTACIO`.
4. Abra qualquer arquivo `.py`.
5. Execute pelo botão de Run do VS Code ou pelo terminal:

```bash
python nome_do_arquivo.py
```

## Observação

Os programas foram feitos para serem independentes e fáceis de editar/analisar. Os exercícios que exigem listas de dicionários, funções, `math` ou `random` seguem os requisitos indicados na lista.
